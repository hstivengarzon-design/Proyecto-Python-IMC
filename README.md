# Proyecto Python - Calculadora de IMC

## Descripción

Este proyecto consiste en una calculadora de Índice de Masa Corporal (IMC) desarrollada en Python.

El programa permite ingresar algunos datos personales como nombre, apellidos, edad, peso y estatura, y posteriormente calcula el IMC de la persona.

## Datos solicitados

- Nombre
- Apellido paterno
- Apellido materno
- Edad
- Peso en kilogramos
- Estatura en metros

## Fórmula utilizada

El IMC se calcula utilizando la siguiente fórmula:

IMC = peso / (estatura ** 2)

## Archivos del proyecto

- `calculadora_imc.py`: contiene el programa principal de la calculadora de IMC.
- `hello_python.py`: contiene un ejercicio básico de Python.
